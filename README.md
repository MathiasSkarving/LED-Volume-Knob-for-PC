# LED Ring Volume Knob

- ##### ESP32S3 (https://www.aliexpress.com/item/1005010579778226.html)
- ##### WS2812B Led ring with 12 LEDS (https://www.aliexpress.com/item/1005008409813637.html)
- ##### Rotary encoder (https://www.aliexpress.com/item/1005009578504178.html)
- ##### 330 Ohm resistor
